# GeoPython

Unificación de bibliotecas de Python para diversas ramas de la geología. Colección de notebooks de práctica y exploración: geoquímica, geología estructural, cartografía, hidrogeología, modelado 3D y ciencia de datos aplicada.

## Índice de carpetas

| [`VolcanicEruptions/`](VolcanicEruptions) | Vulcanología | EDA de erupciones y emisiones (Global Volcanism Program) |
